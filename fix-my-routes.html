Troubleshooting Steps

1. Verify development server is running correctly

lsof -i :3000 - Check if port 3000 is in use
ps aux | grep next - Find Next.js processes

2. Try these alternative URLs:

Fix Role (Alt)

127.0.0.1:3000/fix-role

Admin Force (Alt)

127.0.0.1:3000/admin/force

NEW: Role Fix

Try /role-fix instead
Alternative to fix-role page

NEW: Admin Bypass

Try /admin-bypass instead
Alternative to admin/force page

3. Restart and clear cache:

pkill -f "next" && cd "$(pwd)" && npm run dev

This will stop all Next.js processes and restart the development server.

If Still Not Working

Try the following steps in order:

  1. Close your browser completely and reopen it
  2. Clear browser cache and cookies
  3. Rename the page files to something different and try again
  4. Restart your computer
  5. Check if your antivirus or firewall is blocking connections

Last Resort: If nothing else works, try renaming your project root folder and reinstalling dependencies with npm install.
